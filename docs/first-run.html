CUHK AI Bridge 已安装

请按下面的顺序完成首次使用。安装程序已包含运行所需的 Node、OpenCLI、浏览器扩展文件和 Claude Code Router；不需要运行命令下载这些组件。

1. 安装 Chrome 扩展

  1. 打开 Google Chrome，在地址栏输入 chrome://extensions。
  2. 打开页面右上角的“开发者模式”，点击“加载已解压的扩展程序”。
  3. 从 Windows 开始菜单打开“CUHK AI Bridge → 打开 Chrome 扩展文件夹”，在 Chrome 的选择窗口里选择同一个 extension 文件夹。

扩展会申请浏览器调试、标签页等较广权限。详情见安装目录里的 docs/install.md。

2. 登录学校网站

在同一个 Chrome 中打开 ai.cuhk.edu.cn，自行登录并保持 Chrome 开启。安装程序不会索取或保存你的学校密码。

3. 准备一个命令行客户端

选择并按官方说明安装 Codex CLI 或 Claude Code。只使用其中一种即可。安装完成后，如控制面板未找到客户端，请退出控制面板再打开。

4. 打开控制面板

从开始菜单或桌面快捷方式启动“CUHK AI Bridge”，选择要处理的工作目录、模型和思考强度，然后点击对应客户端的启动按钮。

需要帮助时，请查看 GitHub 问题区。安装目录可以在卸载前自行备份；卸载不会自动删除个人配置和会话数据。
