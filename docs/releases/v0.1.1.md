# CUHK AI Bridge v0.1.1

## 修复

- 英文学校网页可以识别、切换本地 Qwen、GLM 和豆包 Seed 模型，并正确设置思考强度。此前只匹配中文控件名称，会在发送消息前报 `CUHK AI model selector was not found.`，最终向客户端返回 502。
- 模型和思考强度选择继续使用网页 DOM 语义控件。重复、禁用或无法识别的选项不会被随意替代；英文页面无需切换成中文。
- 本版安装包同时纳入 v0.1.0 发布后已合入主分支的双 CLI 启动修复，以及控制面板关闭时清理相关进程的改动。

## 验证与范围

- CUHK 适配器 62 项测试通过。
- Windows 11 虚拟机保持英文页面，单文件修复后本地 Qwen + xhigh 完成 3 次真实命令：输出、写文件、读回。命令退出码均为 0，模型成功汇报结果。
- 上述工具测试保留 elevated Windows 沙箱，策略为 workspace-write、禁止网络访问；使用 headless Codex exec，未覆盖交互审批界面。
- 安装包由版本标签对应的源码通过 Windows installer 工作流构建，执行静默安装、运行时和卸载检查。完整浏览器登录及工具链的全新安装验收，与此前单文件修复的虚拟机验证分别记录。
- 同伴电脑此前的 runner pipe-out 超时尚未确认根因，本修复不据此宣称解决该类错误。

详细原因和测试边界见 [浏览器语言回归记录](../browser-locale-regression.md)。
